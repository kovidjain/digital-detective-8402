# Digital Detective

This public repository contains the Digital Detective independent learning assignment. The missions cover computer fundamentals, Terminal work, operating systems, program execution, number systems, GitHub, and computer networks.

## Topics explored

- IPOS, hardware, software, and everyday computer systems
- Terminal commands, file management, flags, pipes, and package managers
- Operating systems, processes, paths, storage, and permissions
- Python programs, compilers, and interpreters
- Binary, decimal, hexadecimal, and text encoding
- Git, branches, Pull Requests, and collaboration
- Networks, DNS, routers, protocols, and client-server communication

## Learning summary

The assignment will connect practical computer observations with short explanations written from the work completed in each mission. Evidence will be checked and private machine or network details will be removed before publication.
