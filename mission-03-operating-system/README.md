## My understanding

An operating system is the main layer between applications and hardware. It allocates resources, provides a way to interact with files and programs, and applies rules about access. When I open an application, the operating system creates and manages a process, gives it memory and processor time, and helps it read or save data.

## Difficulties faced

The difficult part was separating the operating system from individual applications. An application performs a user task, but the operating system provides shared services such as memory management, file access, and permissions.

## How I resolved them

I described each concept by its responsibility and then followed one example—opening and saving a document—from the application through the operating system to storage.
