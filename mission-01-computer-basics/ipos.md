# Task 1.1 — Trace an activity using IPOS

## Activity: create and save this mission report

| Stage | What happens in this example | Hardware or component |
| --- | --- | --- |
| Input | I type the report text and choose the save command. | Keyboard |
| Processing | The editor and operating system handle the text and save request. The processor runs their instructions and memory holds the active work. | CPU and RAM |
| Output | The report appears on the screen so I can read and check it. | Display |
| Storage | Saving writes the report as a file, and the Git commit keeps a version in the repository history. | SSD or hard drive, then GitHub storage after pushing |

The activity starts when text enters through the keyboard. The processor works on it with help from memory, and the display shows the current result. When I save the file, the operating system writes it to persistent storage. A later Git commit records a version that can be reviewed.
