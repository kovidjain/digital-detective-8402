# Task 1.1 — IPOS activity

## Activity: creating and saving a school assignment

This is a realistic activity because it uses several parts of a computer in one continuous flow. I type an assignment, check what appears on screen, and save the finished file for later use.

| IPOS stage | What happens in this activity | Main examples |
| --- | --- | --- |
| Input | I type words with the keyboard and use the touchpad or mouse to select text, open menus, and choose where to save. | Keyboard, touchpad or mouse |
| Processing | The operating system and writing application interpret my actions, place characters in the document, format the text, and prepare the file to be saved. | Processor, memory, operating system, writing application |
| Output | The completed text and formatting appear on the screen. If I print the assignment, the printer produces a paper copy. | Display, speakers for alerts, printer |
| Storage | The document is written to storage with its name and format, so I can close it and open the same work later. | Internal or removable storage |

## Flow explanation

The flow begins when I enter text or commands. The computer processes each action and updates the document in memory. The screen gives immediate output, which lets me notice mistakes and make changes. When I choose Save, the current document is copied from working memory to storage. If I reopen the file later, it is read from storage and processed again so it can be displayed and edited.

This shows that IPOS can repeat many times during one activity: every typed character is input, processed, and shown as output before the whole document is stored.
