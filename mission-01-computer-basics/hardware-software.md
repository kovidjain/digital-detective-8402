# Task 1.2 — Identify hardware and software

| Item | Hardware or software | Software type | Purpose |
| --- | --- | --- | --- |
| Keyboard | Hardware | Not applicable | Enters text and commands. |
| Display | Hardware | Not applicable | Shows text, images, and results. |
| Processor | Hardware | Not applicable | Executes instructions and calculations. |
| RAM | Hardware | Not applicable | Holds active program data temporarily. |
| macOS | Software | Operating system software | Manages hardware, files, programs, and system resources. |
| Python 3 | Software | Application software | Runs Python programs. |
| Git | Software | Utility software | Records changes to project files. |
| Web browser | Software | Application software | Opens and displays websites. |

Hardware is the physical part of a computer. Software is made of instructions that tell the hardware what to do. Operating-system software manages the computer, application software helps with particular tasks, and utility software supports maintenance or management.
