# Tasks 1.2 and 1.3 — Components and systems

## Task 1.2 — Hardware and software

### Hardware examples

| Hardware item | Classification | Purpose |
| --- | --- | --- |
| Keyboard | Input device | Enters letters, numbers, and commands. |
| Display | Output device | Shows text, images, and application results. |
| Processor (CPU) | Processing component | Executes instructions and performs calculations. |
| Solid-state drive (SSD) | Storage device | Keeps the operating system, applications, and files when power is off. |

### Software examples

| Software example | Classification | Software type | Purpose |
| --- | --- | --- | --- |
| Operating system | System software | Operating system | Manages hardware, files, applications, and user interaction. |
| Web browser | Application software | Internet application | Opens websites and displays web content. |
| Word processor | Application software | Productivity application | Creates, edits, formats, and saves documents. |
| Device driver | System software | Utility/support software | Helps the operating system communicate with a particular hardware device. |

Hardware is the equipment that can be physically handled. Software is the set of programs and instructions that tells the hardware what to do. System software supports the computer itself, while application software helps a user complete a particular task.

## Task 1.3 — Everyday computer-based systems

| System | Purpose | Input | Output |
| --- | --- | --- | --- |
| ATM | Lets a customer view an account and complete cash or account transactions. | Bank card, PIN, selected transaction, and amount. | Screen instructions, receipt, account message, and cash when requested. |
| Supermarket self-checkout | Allows a customer to scan items and pay without a staffed checkout. | Barcode scans, item selections, payment details, and bagging confirmations. | Item list, running total, payment confirmation, receipt, and change when applicable. |
| Traffic-light control system | Coordinates road traffic safely at an intersection. | Vehicle detectors, pedestrian button presses, timers, and programmed rules. | Red, amber, and green light signals plus pedestrian crossing signals. |

These systems all accept information, process it according to rules, and produce a result that a person or another device can use.
