## My understanding

Source code is the human-readable set of instructions written by a programmer. A compiler translates source code into another form before it runs, while an interpreter works through instructions during execution. In both cases, the operating system eventually manages a running process and provides access to memory, files, and other resources.

## Difficulties faced

The terms compiler and interpreter can sound like completely separate categories, even though modern language tools often use more than one stage. It was also easy to confuse a source file with the process created when the file is run.

## How I resolved them

I separated the explanation into source code, translation, execution, and process management. I also described the general workflow rather than claiming that every Python implementation uses exactly the same internal steps.
